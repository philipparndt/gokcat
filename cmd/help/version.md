# gokcat version — print version information

Print the version information of gokcat, including the version number and build details.

## Usage

```
gokcat version [--json]
```

## Flags

| Flag     | Description                              |
|----------|------------------------------------------|
| `--json` | Output version information in JSON format |

## Examples

```bash
# Print version in human-readable format
gokcat version

# Print version as JSON
gokcat version --json
```
